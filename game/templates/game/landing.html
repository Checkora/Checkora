    Under the hood

    It doesn't look at every move. It doesn't have to.

    The engine is written in C++17. It searches the game tree with minimax, and alpha-beta pruning lets it drop a line as soon as it can prove the line is worse than one it already has. The tree on the right is doing exactly that, with fresh numbers every few seconds.

    Django and Python look after accounts, game state and these pages. If a server can't run the compiled engine, a Python version of the same search takes over, so a game never stops.

    Questions

    Before you castle.

    Why does Checkora have two engines?

    The search runs in a C++17 engine because it is fast. Python and Django handle accounts, game state and the pages. A Python version of the same search is the fallback for servers that can't run the compiled one.

    Which time controls can I play?

    Bullet, blitz, rapid and classical presets from one minute to sixty, with or without an increment, or a custom clock. You can pause a game and resume it.

    Does it follow the full rules of chess?

    Yes. Moves are validated on the server, including castling, en passant, promotion, check, checkmate and stalemate.

    Who can see my games?

    Your match history and game analysis are shown only to you. Your username and rating appear on the leaderboard. Deleting your account removes your data.

    Does it cost anything?

    No. Checkora is free to play and the source is MIT licensed.
